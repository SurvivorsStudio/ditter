# STEP 2 · 웹 SQL 콘솔 (`F1` 완성)

**시작 조건**: STEP 1의 스키마 API와 실행 API

## 목표

브라우저에서 쿼리를 입력하고, 실행하고, 결과를 표로 본다. **여기까지는 아직 "그냥 웹 DB 클라이언트"다.** AI도 없고 위험 경고도 없다. 하지만 이 바닥 위에 나머지가 얹힌다.

## 하는 일

- React + Vite + TypeScript, 3분할 레이아웃 (에디터 / 결과 / 사이드바)
- CodeMirror 6 에디터, SQL 문법 하이라이팅
- STEP 1의 스키마 API를 물려서 테이블·컬럼 자동완성
- 실행 → 결과 그리드, 실행 시간, 에러 표시
- 접속 선택 UI (비밀번호는 서버가 갖고 있으므로 화면엔 안 나옴)

## 완료 조건

브라우저에서 SELECT를 실행하면 결과 표와 실행 시간이 보인다.

## 기대치 조정

CodeMirror의 SQL 자동완성은 테이블·컬럼 수준까지는 잘 된다. 하지만 별칭 해석, 서브쿼리 스코프, CTE 인지 자동완성은 제한적이다. 과한 기대는 금물이다.
